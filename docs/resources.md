# Ресурсы игровых персонажей

У перца, помидора и моркови одинаковые относительные пути и одинаковый набор файлов:

```text
src/assets/characters/<id>/
├── manifest.json
└── sprites/
    ├── front/
    │   ├── idle.png
    │   ├── cast.png
    │   ├── walk-a.png
    │   └── walk-b.png
    └── back/
        ├── idle.png
        ├── cast.png
        ├── walk-a.png
        └── walk-b.png
```

Всего 9 файлов на героя: 8 PNG и один manifest. Idle и атака используют по одной позе, ходьба — две. Левое направление получается отражением. Холст всех игровых PNG — 1024×1536, видимая высота — 1150 пикселей, опора — (512,1360). Manifest используется загрузчиком и содержит привязки рук и сведения об исходных изображениях.

Движок трёх мобильных сцен общий: `src/assets/shared/runtime/mobile-battle.js`. Загрузка и рисование персонажей общие: `combat-mix.js`. Фаза шага зависит от фактически пройденного расстояния. При любом движении вверх выбирается back.

GLB самостоятельных 3D-стендов расположены в `src/assets/scenes/3d/<id>/`: только модели, указанные в коде соответствующих страниц. Они не входят в набор 2D-героя. Фоны находятся в `src/assets/shared/backgrounds`.

Папки legacy, исходники, референсы, старые версии, заготовки и неподключённые модели в ресурсы приложения не входят. Старые исходные проекты сохранены. Восстановимая копия удалённых из нового проекта ресурсов находится вне проекта; путь указан в resource-cleanup.json.

Морковь: фронтальные изображения взяты из v7; back-позы — из ранее подготовленного рендера модели с экипировкой. Это не утверждение о полном совпадении художественного стиля двух источников. Новые промежуточные кадры не используются.

Проверка: `npm run check` сравнивает точные списки файлов трёх героев, число поз, размеры PNG, обращения к ресурсам и использование моделей. `npm run build` проверяет Angular-компоненты и шаблоны.
